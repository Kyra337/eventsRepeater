# Events Repeater

Helps University Centers management keep track of data for event attendance. With events reaching 200+ students, this tool helps speed up the process of collecting data.

## Features
- **Feature 1**: Easy to use website for anyone to use.
- **Feature 2**: Can upload up to 10 CSV files at once.
- **Modern Stack**: Built with Python, Python Standard Library, and Streamlit.
